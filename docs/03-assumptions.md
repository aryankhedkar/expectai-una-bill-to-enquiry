# 3. Assumptions

- The assumed answers in the questions document above.
- All data is synthetic. The businesses, suppliers, addresses and meter numbers are invented.
- The reader replays recorded model output unless a model key is set, so the walkthrough and the tests give the same result on every run.
- Photos and scans would need OCR or a vision model in front of the reader. The sketch starts from a document with readable lines.
- Every money figure is in pounds sterling and every rate is in pence.
- The demo treats 23 November 2026 as today, so dates and countdowns do not drift.
- One bill means one electricity meter at one site for one billing period.
