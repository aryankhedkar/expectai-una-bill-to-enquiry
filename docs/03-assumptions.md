# 3. Assumptions

The sketch rests on the following assumptions, and each of them can be argued with.

- The answers I assumed in the questions document above all hold.
- All of the data is synthetic, so the businesses, suppliers, addresses and meter numbers are invented.
- The reader replays recorded model output unless a model key is set, so the walkthrough and the tests give the same result on each run.
- Photos and scans would need OCR or a vision model in front of the reader, which is why the sketch starts from a document with readable lines.
- Money is in pounds sterling and rates are in pence.
- The demo treats 23 November 2026 as today, so dates and countdowns do not drift.
- One bill covers one electricity meter at one site for one billing period.
